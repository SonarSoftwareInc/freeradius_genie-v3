# freeRADIUS Genie v3
An installer to setup and configure freeRADIUS v3 for use with Sonar.

## Introduction
This repository contains everything needed to provide your [Sonar](https://sonar.software) V2 instance an integration with
freeRADIUS.  This includes a tool called `genie` that automates the setup and configuration of your freeRADIUS server.

This installer is designed to be run on [Ubuntu 24.04 64bit](http://www.ubuntu.com/download/server) with freeRADIUS 3, but should work on most versions of Ubuntu. Download and install Ubuntu on the server you wish to run FreeRADIUS on.

## Sonar Configuration
Directions for setting this up can be found in the [Sonar Knowledge Base](https://docs.sonar.expert/networking/free-radius-3-build-out-integration).
